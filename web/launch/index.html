What Spark Grid 1.1.0 includes

Spreadsheets. No account.

A free native Mac spreadsheet that opens and saves .xlsx and CSV on your machine, with everyday formulas and formatting, and without an account.

View on GitHub

macOS 14 or later · Free · No account · No analytics · The app does not use the network

What’s New

Large workbooks open faster, and scrolling back to a page you’ve already seen is instant. Formula cells show their results. Sheet tabs stay in the file’s order. Blank formulas stay blank when the file is opened in Excel. Selecting a merged cell no longer jumps the view. Command-A in the formula field selects the formula.

The longer notes are on the changelog.

What 1.1.0 does

  • New, Open, Save, and Save As for .xlsx and CSV. Autosave writes the file you already saved. Recent files. One window. New, Open, and a Finder open ask before they replace a file that has unsaved changes. Quit asks the same question.
  • Selection, freeze panes, merge, fill handle, zoom, resize, and a formula bar that stays in sync with the cell. Command-A in the formula field selects that field’s text. Selecting a merged cell keeps the view on the cell you clicked.
  • A cell with a formula shows the result. The formula stays in the formula bar. Formulas Excel saved as blank stay blank on export, instead of showing 0 before Excel recalculates.
  • Formulas that evaluate: SUM, AVERAGE, COUNT, COUNTA, MIN, MAX, IF, IFERROR, AND, OR, ABS, ROUND, LEN, LEFT, RIGHT, TRIM, CONCAT, CONCATENATE, TEXT, XLOOKUP, VLOOKUP, HLOOKUP, INDEX, MATCH, XMATCH, TODAY, DATE, YEAR, MONTH, DAY, SUMIF, AVERAGEIF, COUNTIF, SUMIFS, COUNTIFS, AVERAGEIFS, COUNTBLANK, SUMPRODUCT, IFNA, IFS, NOT, UPPER, LOWER, MID, SUBSTITUTE, TEXTJOIN, ROUNDUP, ROUNDDOWN, NOW, COLUMN, CHAR, and TRUE. Criteria that take wildcards can use them. Anything else shows #NAME?.
  • Fonts, colors, borders, alignment, and conditional formatting (highlights, color scales, data bars, and three icon sets). Number formats keep the file’s format code, including thousands separators, the currency symbol in that code, and the date and time pattern.
  • AutoFilter by value, a one-column sort, and find and replace on the current sheet.
  • Pictures you can move and resize.
  • Charts on the sheet: bar, line, or area. Drag to move and resize. Series color, point colors, title, legend, axis titles, and gridlines.
  • Several sheets: add, rename, delete, switch. Sheet tabs open and save in the same order as Excel. Defined names already in an Excel file are read on import, and names you create export. Print preview for the selection, used range, sheet, or workbook.
  • Opening a large workbook is much faster. Saving and autosave no longer freeze the window while the file is written. Switching sheets is immediate, and the values already calculated stay put. Scrolling a page you have already seen is instant. The first visit to a new part of a large sheet can still hitch.

What 1.1.0 leaves out

  • Spark Grid is not Excel or Numbers. No pivot tables, data-validation lists, comments, or live collaboration.
  • Pie, scatter, and charts with more than one series.
  • The fill handle copies. It does not continue 1, 2, 3 or a series of dates.
  • The column menu filters by a checklist of values. It does not sort, and it does not filter by greater than, less than, or text contains.
  • The formula bar shows the cell address. It does not take an address or a defined name. There is no F2 to edit, and no ⌘-arrow to the edge of the data.

Coming next

None of this is in version 1.1.0.

  • The fill handle continues numbers and dates. Formulas still shift.
  • The column menu can sort, and filter by greater than, less than, or text contains, beside the value checklist.
  • A name box that takes an address or a defined name, F2 to edit, and ⌘-arrow to the edge of the data.
