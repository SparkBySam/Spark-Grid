Privacy Policy

Last updated: September 11, 2026

Spark Grid is a native macOS spreadsheet application created by Sam Parker. This policy describes how the app handles information.

Data collection

Spark Grid does not collect personal data, analytics, advertising identifiers, or usage telemetry. Spreadsheet files you open or save remain on your Mac (and any locations you choose, such as iCloud Drive or local folders).

Local preferences

The app stores preferences on your device (for example appearance and keyboard shortcuts) using standard macOS user defaults. These settings are not transmitted to us.

Network

The application does not require a network connection for core spreadsheet features. Links in the About window (feedback email, tip jar, Spark Suite site, terms) open only when you choose them.

Children

Spark Grid does not target children and does not knowingly collect data from anyone.
