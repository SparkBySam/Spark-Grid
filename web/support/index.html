Spark Grid support

Last updated: October 14, 2026

Need help with Spark Grid? Email Sam — every message gets read.

help@sparkgridapp.com

Spark Grid 1.1.0 is free on the Mac App Store. Spreadsheets. No account.

What to include in a bug report

  • Your macOS version (Apple menu → About This Mac)
  • Spark Grid version (Spark Grid → About Spark Grid)
  • What you were doing, and what went wrong
  • A sample workbook if the issue is file-specific (remove anything private first)

Opening .xlsx and CSV

Spark Grid opens and saves .xlsx and CSV from Open, or when you drop a file on the icon. Pressing Space in Finder does not open Spark Grid for those files. Pivot tables are not in this version. Bar, line, and area charts are on the sheet. If a file breaks, email a sample with private data removed. What 1.1.0 includes.

Formulas in version 1.1.0

These names evaluate: SUM, AVERAGE, COUNT, COUNTA, MIN, MAX, IF, IFERROR, AND, OR, ABS, ROUND, LEN, LEFT, RIGHT, TRIM, CONCAT, CONCATENATE, TEXT, XLOOKUP, VLOOKUP, HLOOKUP, INDEX, MATCH, XMATCH, TODAY, DATE, YEAR, MONTH, DAY, SUMIF, AVERAGEIF, COUNTIF, SUMIFS, COUNTIFS, AVERAGEIFS, COUNTBLANK, SUMPRODUCT, IFNA, IFS, NOT, UPPER, LOWER, MID, SUBSTITUTE, TEXTJOIN, ROUNDUP, ROUNDDOWN, NOW, COLUMN, CHAR, and TRUE. Criteria that take wildcards can use them. Anything else shows #NAME?.

Coming next

Not in version 1.1.0: a fill that continues numbers and dates, a column menu that sorts and filters by greater than, less than, or text contains, and a name box that takes an address or a defined name, with F2 to edit and ⌘-arrow to the edge of the data.
