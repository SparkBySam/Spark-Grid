Spark Grid support

Last updated: October 7, 2026

Need help with Spark Grid? Email Sam — every message gets read.

help@sparkgridapp.com

Spark Grid 1.0 is free on the Mac App Store.

What to include in a bug report

  • Your macOS version (Apple menu → About This Mac)
  • Spark Grid version (Spark Grid → About Spark Grid)
  • What you were doing, and what went wrong
  • A sample workbook if the issue is file-specific (remove anything private first)

Opening .xlsx and CSV

Spark Grid opens and saves .xlsx and CSV from Open, or when you drop a file on the icon. Pressing Space in Finder does not open Spark Grid for those files. Pivot tables, SUMIF, and charts stored in an Excel file are not imported. If a file breaks, email a sample with private data removed. What 1.0 includes.

Formulas in version 1.0

These names evaluate: SUM, AVERAGE, COUNT, COUNTA, MIN, MAX, IF, IFERROR, AND, OR, ABS, ROUND, LEN, LEFT, RIGHT, TRIM, CONCAT, CONCATENATE, TEXT, XLOOKUP, VLOOKUP, INDEX, MATCH, TODAY, DATE, YEAR, MONTH, and DAY. Anything else shows #NAME?.
