Support

Last updated: September 11, 2026

Need help with Spark Grid? Email us — we read every message.

help@sparkgridapp.com

What to include

  • Your macOS version (Apple menu → About This Mac)
  • Spark Grid version (Spark Grid → About Spark Grid)
  • What you were doing, and what went wrong
  • A sample workbook if the issue is file-specific (remove anything private first)

Common topics

  • Opening Excel files — Spark Grid opens `.xlsx` and CSV. Some Excel-only features may not round-trip perfectly yet.
  • Formulas — Supported functions include common aggregates and logic; unsupported names show as errors in-cell.
  • Privacy — The app does not collect analytics. See the Privacy Policy.
